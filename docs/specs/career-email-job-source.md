# Spec: Career Email Job Source

## Objective

Add `CAREER_EMAIL` as a new `JobSource` value. In Pakistan many companies collect applications directly via a careers@company.com-style inbox rather than a job board or a company career-portal page. Today those applications get miscategorized as `COMPANY_WEBSITE` or `OTHER`. Success: user can tag a job "Career Email" in Quick Add and the manual job form, see it in filters, funnel chart, and source badge, same as the other five source values.

## Assumptions

1. Enum value name: `CAREER_EMAIL` (label "Career Email"). Correct me if you want `COMPANY_EMAIL` instead.
2. No auto-detection needed — `guessSourceFromUrl` (backend/src/modules/jobs/jobs.service.ts:56) stays domain-based; email-sourced applications have no URL to guess from, user picks it manually. Not in scope: parsing `mailto:` links or email addresses.
3. Position in the source list/badge order: after `REFERRAL`, before `OTHER` — matches how `ROZEE`/`COMPANY_WEBSITE`/`REFERRAL` were appended historically (backend prisma migration `20260716085911_add_job_source`).
4. This is an additive enum change — no backfill of existing `COMPANY_WEBSITE`/`OTHER` rows to the new value.

## Tech Stack

Existing stack, no new dependencies: NestJS + Prisma 7 + PostgreSQL (backend), Next.js 16 + TanStack Query + RHF/Zod (frontend).

## Code Style

Match existing enum-extension pattern exactly — e.g. how `ROZEE` was added in migration `20260716085911_add_job_source`. Backend:

```prisma
enum JobSource {
  LINKEDIN
  INDEED
  ROZEE
  COMPANY_WEBSITE
  REFERRAL
  CAREER_EMAIL
  OTHER
}
```

Frontend (`types/index.ts`), keep arrays/records in the same order as the Prisma enum:

```ts
export const JOB_SOURCES = [
  'LINKEDIN', 'INDEED', 'ROZEE', 'COMPANY_WEBSITE', 'REFERRAL', 'CAREER_EMAIL', 'OTHER',
] as const;

SOURCE_LABELS: { ..., CAREER_EMAIL: 'Career Email', ... }
SOURCE_COLORS: { ..., CAREER_EMAIL: 'bg-<color>-100 text-<color>-700 dark:bg-<color>-900/40 dark:text-<color>-300', ... }
```
Pick an unused Tailwind color family (not sky/orange/teal/purple/pink already in use) for `SOURCE_COLORS.CAREER_EMAIL` — check `frontend/types/index.ts:257-265` for what's taken before choosing.
