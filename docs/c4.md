# C4 model

Job Tracker's architecture at the first three [C4](https://c4model.com) levels: system context, containers, and the components inside the API. The code level is left out — the source is the reference. For request-level flows see [`architecture.md`](./architecture.md) and [`uml.md`](./uml.md).

A hand-drawn version of the same three levels, with light and dark themes, is on the data flow page: [context](https://claude.ai/artifact/XE3NMk5ubDKpuLh1LnMUXm#c4), [containers](https://claude.ai/artifact/XE3NMk5ubDKpuLh1LnMUXm#c4-containers), [components](https://claude.ai/artifact/XE3NMk5ubDKpuLh1LnMUXm#c4-components) (private; needs the owner's claude.ai sign-in).

The diagrams use Mermaid flowcharts styled with C4 conventions rather than Mermaid's experimental `C4Context` syntax, whose automatic layout overlaps labels on GitHub. Every box names its element type in brackets; colours follow the usual C4 key:

- Dark blue — person
- Blue — Job Tracker itself (system, container)
- Light blue — component
- Grey — external system
- Dashed border — system or container boundary

## Level 1 — System context

Who uses Job Tracker and which outside systems it depends on.

```mermaid
flowchart LR
    user(["<b>Job seeker</b><br/>[Person]<br/>Tracks applications, target<br/>companies and interviews"])
    jt["<b>Job Tracker</b><br/>[Software System]<br/>Web app, API and browser<br/>extension for a job search"]

    oauth["<b>Google / GitHub</b><br/>[Software System]<br/>OAuth sign-in"]
    groq["<b>Groq</b><br/>[Software System]<br/>Hosted LLM, gpt-oss-120b"]
    tavily["<b>Tavily</b><br/>[Software System]<br/>Web search API"]
    sites["<b>Company websites</b><br/>[Software System]<br/>Homepage and /about pages"]
    resend["<b>Resend</b><br/>[Software System]<br/>Transactional email"]

    user -->|"Tracks jobs, companies, interviews<br/>[HTTPS]"| jt
    jt -->|"Signs users in<br/>[OAuth 2.0]"| oauth
    jt -->|"Parses postings, extracts facts,<br/>summarizes timelines [HTTPS]"| groq
    jt -->|"Searches company and<br/>posting info [HTTPS]"| tavily
    jt -->|"Fetches page text<br/>[HTTPS]"| sites
    jt -->|"Sends reminders and digests<br/>[HTTPS]"| resend
    resend -.->|Emails reminders, digests| user

    classDef person fill:#08427b,stroke:#052e56,color:#fff
    classDef system fill:#1168bd,stroke:#0b4884,color:#fff
    classDef external fill:#999999,stroke:#6b6b6b,color:#fff
    class user person
    class jt system
    class oauth,groq,tavily,sites,resend external
```

## Level 2 — Containers

The separately deployed or data-holding parts of Job Tracker. Deployment detail (VM, Docker Compose, Vercel) is in [`architecture.md`](./architecture.md#deployment-topology).

```mermaid
flowchart LR
    user(["<b>Job seeker</b><br/>[Person]"])

    subgraph jt["Job Tracker — Software System"]
        web["<b>Web app</b><br/>[Container: Next.js, React,<br/>TanStack Query — Vercel]<br/>Jobs board, companies,<br/>interviews, profile, admin"]
        ext["<b>Browser extension</b><br/>[Container: Chrome MV3]<br/>Imports the posting<br/>in the open tab"]
        proxy["<b>Reverse proxy</b><br/>[Container: Caddy 2]<br/>TLS termination, compression"]
        api["<b>API</b><br/>[Container: NestJS, Prisma, BullMQ]<br/>REST API, crons,<br/>background workers"]
        db[("<b>Database</b><br/>[Container: PostgreSQL on Neon]<br/>Store of record")]
        redis[("<b>Queue store</b><br/>[Container: Redis 7]<br/>BullMQ jobs, OAuth codes")]
        files[("<b>File storage</b><br/>[Container: Oracle Object<br/>Storage, S3 API]<br/>Resume PDFs")]
    end

    subgraph externals["External systems"]
        oauth["<b>Google / GitHub</b><br/>[Software System]<br/>OAuth"]
        ai["<b>Groq and Tavily</b><br/>[Software System]<br/>LLM and web search"]
        resend["<b>Resend</b><br/>[Software System]<br/>Email"]
    end

    user -->|"Uses [HTTPS]"| web
    user -->|"Clicks Import"| ext
    web -->|"JSON API calls, Bearer JWT<br/>+ refresh cookie [HTTPS]"| proxy
    ext -->|"PAT exchange, parse and<br/>create job [HTTPS]"| proxy
    proxy -->|"Forwards [HTTP :3001]"| api
    api -->|"Reads and writes<br/>[Prisma, SQL/TLS]"| db
    api -->|"Enqueues and consumes<br/>[RESP]"| redis
    api -->|"Stores, deletes, presigns<br/>[S3 API]"| files
    web -.->|"Downloads resume via<br/>presigned URL [HTTPS]"| files
    api -->|"Redirects, fetches profile<br/>[OAuth 2.0]"| oauth
    api -->|"Prompts and searches<br/>[HTTPS]"| ai
    api -->|"Sends email [HTTPS]"| resend

    classDef person fill:#08427b,stroke:#052e56,color:#fff
    classDef container fill:#438dd5,stroke:#2e6295,color:#fff
    classDef external fill:#999999,stroke:#6b6b6b,color:#fff
    class user person
    class web,ext,proxy,api,db,redis,files container
    class oauth,ai,resend external
    style jt fill:none,stroke:#444,stroke-dasharray:6 4
    style externals fill:none,stroke:none
```

## Level 3 — Components of the API

NestJS modules inside the API container. Every feature module reads and writes Postgres through the global `PrismaService`; those arrows are left out to keep the diagram readable.

```mermaid
flowchart TB
    web["<b>Web app</b><br/>[Container: Next.js]"]
    ext["<b>Browser extension</b><br/>[Container: Chrome MV3]"]

    subgraph api["API — Container: NestJS"]
        direction LR
        subgraph http["Request handling"]
            direction TB
            auth["<b>Auth</b><br/>[Component: AuthModule]<br/>JWT + refresh rotation,<br/>OAuth, PAT exchange"]
            jobs["<b>Jobs</b><br/>[Component: JobsModule]<br/>Jobs, JobEvent log,<br/>stats, posting parser"]
            companies["<b>Companies</b><br/>[Component: CompaniesModule]<br/>Companies, CSV import,<br/>enrichment trigger"]
            contacts["<b>Contacts</b><br/>[Component: ContactsModule]<br/>Owned via parent<br/>job or company"]
            rounds["<b>Interview rounds</b><br/>[Component: InterviewRoundsModule]<br/>Rounds, round prep"]
            resumes["<b>Resumes</b><br/>[Component: ResumesModule]<br/>PDF upload, download URLs"]
        end
        subgraph background["Background"]
            direction TB
            sched["<b>Schedulers</b><br/>[Component: cron jobs]<br/>Hourly reminders and digests"]
            workers["<b>Workers</b><br/>[Component: BullMQ processors]<br/>Enrichment, timeline<br/>summary, notifications"]
        end
        subgraph shared["Shared services"]
            direction TB
            llm["<b>Enrichment services</b><br/>[Component: LlmService,<br/>SearchService, WebFetchService]"]
            storage["<b>Storage</b><br/>[Component: StorageService]<br/>Local or Oracle driver"]
        end
    end

    redis[("<b>Queue store</b><br/>[Container: Redis 7]")]
    files[("<b>File storage</b><br/>[Container: Oracle Object Storage]")]
    ai["<b>Groq and Tavily</b><br/>[Software System]"]
    resend["<b>Resend</b><br/>[Software System]"]

    web -->|"JSON [HTTPS]"| http
    ext -->|"Parse, create job [HTTPS]"| jobs
    jobs -->|parses postings| llm
    rounds -->|generates round prep| llm
    jobs -.->|"enqueues enrichment, summaries"| redis
    companies -.->|enqueues enrichment| redis
    sched -.->|enqueues reminders, digests| redis
    redis -.->|delivers jobs| workers
    workers -->|extracts, summarizes| llm
    workers -->|"sends email [HTTPS]"| resend
    llm -->|"calls [HTTPS]"| ai
    resumes -->|stores PDFs| storage
    storage -->|"S3 API"| files

    classDef container fill:#438dd5,stroke:#2e6295,color:#fff
    classDef component fill:#85bbf0,stroke:#5d82a8,color:#000
    classDef external fill:#999999,stroke:#6b6b6b,color:#fff
    class web,ext,redis,files container
    class auth,jobs,companies,contacts,rounds,resumes,sched,workers,llm,storage component
    class ai,resend external
    style api fill:none,stroke:#444,stroke-dasharray:6 4
    style http fill:none,stroke:#999,stroke-dasharray:3 3
    style background fill:none,stroke:#999,stroke-dasharray:3 3
    style shared fill:none,stroke:#999,stroke-dasharray:3 3
```

Tokens, users, admin and health modules are omitted.
